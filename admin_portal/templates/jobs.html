Jobs

Pipeline scripts run here as background processes on this machine. The live dashboard opens OpenCV preview windows on whichever machine runs this portal server — if that's headless, use its own terminal output/logs below instead of expecting a window to appear.

The restreamer (go2rtc) is what makes live camera viewing in Live Monitoring possible — browsers can't play RTSP directly, so go2rtc converts each camera's RTSP feed into WebRTC that a <video> element can show. It needs the go2rtc binary at bin/go2rtc (download from github.com/AlexxIT/go2rtc/releases, then chmod +x bin/go2rtc) and won't start without it. Everything else — detection overlays, heatmaps, counts, insights — works without it; only live video needs it.
